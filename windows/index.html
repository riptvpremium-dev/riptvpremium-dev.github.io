RIptv pour Windows

Pour un PC sous Windows 10 ou 11 (64 bits). Aucun droit administrateur n'est nécessaire pour RIptv.

  1. Installe VLC 64 bits (gratuit) : RIptv s'en sert pour lire les vidéos.
    Télécharger VLC
    Le grand bouton de la page de VideoLAN donne la bonne version (64 bits).
  2. Télécharge RIptv (environ 140 Mo) :
    Télécharger RIptv pour Windows
  3. Fais un clic droit sur le fichier téléchargé ▸ Extraire tout.
  4. Dans le dossier RIptv extrait, double-clique sur « Installer RIptv ».
    Si Windows affiche « Windows a protégé votre ordinateur » : « Informations complémentaires » ▸ « Exécuter quand même ».
  5. Un raccourci RIptv apparaît sur le Bureau et dans le menu Démarrer. Pour retrouver tes listes et tes favoris : écran « Sources » ▸ « Synchronisation Google », avec le même compte que sur ta box ou ton téléphone (un QR code à scanner s'affiche).

RIptv se met ensuite à jour tout seul à chaque démarrage. Fichiers officiels publiés sur GitHub. RIptv
